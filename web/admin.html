导入专业班级（本课程）

表头需要包含：学院、班级、计划人数、专业简称、年级、校区（「实际上课人数」「人数」也会被识别为计划人数）。 支持 .xlsx 与 .csv，同一文件中重复的班级会提示跳过。导入的班级只属于当前课程。

导入选班教师名单（本课程）

表头需要包含：姓名、工号，两项都必填（教师登录时工号与姓名必须同时匹配，没有工号的教师无法登录）。 在本课程界面导入后，这些教师即自动加入本课程名单；即使还没选班，也会出现在总览、教师选班情况与导出结果中。
单个添加： 添加后即加入本课程名单，教师用工号+姓名登录

选班人数上下限

「上限」= 一个班最多可被几位教师选（默认 1，即排他）；「下限」= 该班至少需要几位教师选，低于下限会在总览里标黄提示。
统一设置： 上限 下限 |
教师规则： 每位教师最多 人（0=不限） 至少 个班
班级专业简称校区 计划人数上限下限

导出本课程选班结果

导出的 Excel 包含四张表：选班明细（含排课备注）、未选班级、教师汇总（含状态）、未选班教师名单。

以下操作只影响当前课程，请谨慎使用。清空选班仅删除选班记录；清空班级会同时删除选班记录、保留教师名单；清空教师名单会同时删除选班记录和情况说明、保留班级。

管理员密码

所有课程共用一个管理员密码。修改后其他已登录的管理端需重新登录；服务器上也可用 python app.py --set-password 新密码 直接重置。
